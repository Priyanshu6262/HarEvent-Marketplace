# HarEvent Public Assets

Place these two files in this folder before running `npm run dev`:

1. **`harevent_hero_bg_1672x696.png`** — The hero section background image  
   Referenced as: `/assets/harevent_hero_bg_1672x696.png`

2. **`harevent-logo.png`** — The transparent HarEvent logo  
   Referenced as: `/assets/harevent-logo.png`

If the logo is not present, the header will automatically display a stylized text fallback "HarEvent" instead.
If the hero background is not present, the section will display the brand's warm cream gradient as a fallback.
